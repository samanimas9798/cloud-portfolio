## Cloud Portfolio Website

This is a static website hosted on an AWS EC2 instance using Nginx showcasing my portfolio.

## Features

- Static HTML and CSS portfolio
- Hosted on AWS EC2
- Served using Nginx
- Accessible through a public IP address

## Technologies Used

- AWS EC2
- Ubuntu Linux
- Nginx
- HTML
- CSS
- SSH
- SCP

## Skills Demonstrated

- Linux server administration
- Deploying a website to AWS EC2
- Secure remote access using SSH
- File transfer using SCP
- Basic web hosting
